## Checklist log (what was reviewed today)

Use ✓ = reviewed, no obvious issue noted today · ⚠ = issue noted (see table above) · N/A = not present / not accessible  

### Exterior & envelope
- [ ] Roof visible areas (from ground / safe vantage only)  
- [ ] Gutters & downspouts (flow, debris)  
- [ ] Siding / trim (damage, pest entry, paint)  
- [ ] Caulk & seals (windows, doors, penetrations)  
- [ ] Grading / drainage (obvious pooling near foundation)  

### Plumbing (visual / user-accessible)
- [ ] Main water shutoff (location confirmed, operable if safely tested)  
- [ ] Under-sink cabinets (all baths + kitchen)  
- [ ] Toilets (stability, supply, obvious leaks at base)  
- [ ] Water heater (visible leaks, venting path if applicable)  
- [ ] Washing machine hoses / laundry box  

### Electrical (visual / non-invasive)
- [ ] GFCI test (where accessible)  
- [ ] Visible outlets/switches (damage, cover plates)  
- [ ] Panel exterior only — **do not open unless you are qualified** [✓ / N/A / Refer to electrician]  
- [ ] Extension cords / obvious hazards  

### HVAC & mechanical (basic homeowner-level)
- [ ] Filter size noted / condition  
- [ ] Thermostat operation (basic)  
- [ ] Outdoor condenser (debris clearance if safe)  
- [ ] Bathroom/kitchen exhaust fans (obvious operation)  

### Fire & life safety
- [ ] Smoke alarms (age/type if labeled, test if owner approves)  
- [ ] CO alarms (presence, test if owner approves)  
- [ ] Fire extinguisher (pressure gauge / date if visible)  
- [ ] Dryer vent — exterior lint/obvious restriction **or** note “recommend pro cleaning if long run”  

### Interior & doors
- [ ] Exterior doors (weatherstrip, lock, sweep)  
- [ ] Windows (operation, obvious seal failure)  
- [ ] Stairs & handrails (loose, damage)  

### Garage
- [ ] Auto-reverse / sensors (basic test if safe)
